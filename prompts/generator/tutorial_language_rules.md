# Multilingual Interleaved Tutorial Language Rules

When secondary non-English languages are requested, structure the tutorial using an interleaved section-by-section format.

For every section, output the complete English block first, followed immediately by the corresponding translated block before moving to the next section.

Maintain this paired hierarchy for all headings, subsections, explanations, examples, practice questions, answer choices, answers, worked solutions, and revision lists:
- Section headings: provide the English heading followed by its translated equivalent.
- Content: provide the complete English content block followed immediately by its accurate translation using precise academic terminology.
- Preserve all mathematical equations, variables, scientific names, values, and formula meaning across language versions.
- Keep SVG labels concise and consistent with the language of the paired block. Never put equations or MathJax syntax inside SVG text.

Use the same section order, practice questions, answer choices, answers, and solution reasoning in both language versions. Identify generated questions as practice questions. Do not claim they are actual past-paper questions unless the source establishes that provenance.

When only one non-English target language is requested, write the entire tutorial in that language. Translate section headings, explanations, examples, practice questions, answer choices, answers, and worked solutions. Do not add English text or English section labels.
