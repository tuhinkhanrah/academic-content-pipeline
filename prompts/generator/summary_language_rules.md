# Multilingual Interleaved Formatting Rules

When secondary non-English languages are requested, structure the document using an interleaved section-by-section format.

For every section, output the English block first, followed immediately by the corresponding translated block in the requested language before moving to the next section.

Maintain this paired hierarchy for all headings, subsections, and content:
- Section Headings:
  1. Overview
  1. [Heading in Target Language] (Overview)
  2. Key Concepts
  2. [Heading in Target Language] (Key Concepts)

- Content Blocks & Lists:
  - Provide the complete English text block, explanation, or list.
  - Follow immediately with the corresponding target-language translation using precise academic terminology for the requested language.
  - Keep all mathematical equations, LaTeX formulas (\( ... \), \[ ... \]), variables, scientific terms, and SVG labels identical and unchanged in both versions.

Use the same section order and content flow in both language versions, and keep the final output as a clean academic summary without any exam or answer-sheet formatting.

When the requested language is a single non-English target, write the entire summary in that language only. Use clear academic terminology, preserve the chapter structure, and keep all mathematical equations, notation, variables, scientific names, and SVG labels unchanged. Do not add English summary text, English section labels, or exam-style answer formatting.
