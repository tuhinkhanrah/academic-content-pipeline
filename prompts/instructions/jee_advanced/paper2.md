# JEE (Advanced) Paper 2 - Exam Structure & Instructions

The structural layout and grading guidelines are uniform across all three core subjects: **Mathematics**, **Physics**, and **Chemistry**.

---

### Section 1: Single Correct Option
* **Question Count**: 4 questions per subject.
* **Format**: Multiple Choice Questions (MCQs) with four options; exactly one option is correct.
* **Mark Scheme**:
  * **Full Marks**: **+3** if ONLY the correct option is chosen.
  * **Zero Marks**: **0** if the question is unanswered.
  * **Negative Marks**: **−1** in all other cases.

---

### Section 2: One or More Than One Correct Option
* **Question Count**: 5 questions per subject.
* **Format**: MCQs where one or more than one option can be correct.
* **Mark Scheme**:
  * **Full Marks**: **+4** ONLY if all correct options are chosen.
  * **Partial Marks (+3)**: If all four options are correct, but ONLY three options are chosen (all being correct).
  * **Partial Marks (+2)**: If three or more options are correct, but ONLY two options are chosen, both of which are correct.
  * **Partial Marks (+1)**: If two or more options are correct, but ONLY one option is chosen and it is a correct option.
  * **Zero Marks**: **0** if none of the options is chosen.
  * **Negative Marks**: **−1** in all other cases.

---

### Section 3: Numerical Value
* **Question Count**: 5 questions per subject.
* **Format**: The answer is a numerical value entered using an on-screen virtual numeric keypad. Numerical values with more than two decimal places must be truncated/rounded off to two decimal places.
* **Mark Scheme**:
  * **Full Marks**: **+4** if ONLY the correct numerical value is entered.
  * **Zero Marks**: **0** in all other cases (no negative marking).

---

### Section 4: Numerical Value (Question Stems)
* **Structure Count**: 2 distinct question stems per subject.
* **Question Count**: 2 questions associated with each stem (total 4 questions per subject).
* **Format**: The answer is a numerical value entered using an on-screen virtual numeric keypad. Numerical values with more than two decimal places must be truncated/rounded off to two decimal places.
* **Mark Scheme**:
  * **Full Marks**: **+2** if ONLY the correct numerical value is entered.
  * **Zero Marks**: **0** in all other cases (no negative marking).
